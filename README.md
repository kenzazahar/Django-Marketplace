# Django-Marketplace

A marketplace web application built with Django, supporting item listings and buyer-seller conversations.

## What it does

Lets users list items for sale, browse listings, and message each other about them, with a dashboard for managing activity.

## Structure

- `item/` — item listings
- `conversation/` — buyer-seller messaging
- `dashboard/` — user dashboard
- `core/` — shared app logic

## Stack

Django (Python) · SQLite (development) · Django templating

## Context

A personal project exploring Django's app-based architecture through a real marketplace use case.
